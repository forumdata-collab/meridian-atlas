# 數據、模型與來源

## 目錄口徑

362 個十四經經穴條目依 GB/T 12346-2021；51 個國標奇穴條目依 GB/T 40997-2021；6 個補充條目另列。合計 419 條記錄，不是 419 個唯一顯示標記：雙側穴和組合穴存在多個標記。

國標編碼、穴名、拼音、基本位置關係、來源頁碼與本項目的三維示意分別存儲。WHO 361 穴目錄與現行國標的差別、古歌穴序與現代穴序差異另列説明。參考入口見應用 `/sources` 和各數據文件中的 URL、版本及頁碼。

## 分層來源

| 層次 | 主要文件與邊界 |
| --- | --- |
| 名稱、編號、讀音 | `national-standard.json`、`extra-standard.json`、`point-pronunciation.json`；源事實與條款索引 |
| 定位事實 | `standard-location-facts.json`；以區域、解剖關係、方向與距離等結構化事實表示，不附完整標準 PDF |
| 古籍與傳統主治 | `classics.ts`、`primary-indication-scan.json` 等；古籍原文節選、整理摘要和來源記錄分開 |
| 來源索引 | `point-reference.json`；早期參考 TARA 的事實關鍵詞與頁碼索引，未包含其原始 CSV 或現代書籍全文 |
| 配穴 | `combinations.ts` 等；公開文獻與古籍用穴的學習記錄，不是個體治療建議 |
| 示意幾何 | `mesh-registration.json`、`*course.json`、`luo-surface.json`；項目整理的綁定、區域曲線和出處説明 |

事實、通用名稱、古籍原文及外部權利人的作品不因本項目採用 AGPL 而產生新的排他權利。對於第三方來源，請按原發布方條件取得和使用；鏈接不等於再分發授權。

## 人體模型

當前人體來自 MakeHuman Community 的 CC0 核心資產，固定原始提交 `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`。提取 body 分組、排除輔助對象、歸一化後採用既有學習體位。具體來源、轉換參數、輸入輸出哈希見 `public/models/model-provenance.json`。

雙手甲面參考通過與該底模相同的源拓撲識別；這是模型內部的方向參照，不是人體甲溝的臨牀標註。其它外部骨骼/手部模型曾用於獨立研究，沒有打包成當前運行人體。

## 審校與貢獻

新的校訂需記錄源版本、具體頁碼或條款、改動對象與驗證方法。3D 改動需要與保留底模建立對應，檢查雙側及經絡依賴。區域模板、表面吸附、作者材質分區、真實骨性參照是不同層次的證據，不能混稱為“已校準”。

目前全身逐穴解剖審校未完成。歡迎帶着可復現證據提交校訂；請勿上傳無再分發授權的書籍掃描、數據庫、模型權重或患者信息。
