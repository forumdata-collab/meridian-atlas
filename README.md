讀到「中府雲門天府訣」，能不能直接看到這些穴位在人體上的關係？學到「寅時肺經」，能不能沿著發亮的經線看它如何運行？遇到「髎、郄、滎」，能不能隨手查讀音？

**Meridian Atlas 是一個中文優先的互動式經絡學習空間。** 它把可旋轉的人體、經絡點選、穴位分類、古籍歌訣、注音、傳統時辰與配穴文獻放進同一個應用。適合自主學習、課堂演示，以及開放的中醫知識視覺化研究。

無需帳號或外部 AI API 密鑰。原始碼、應用數據、人體模型和測試隨倉庫提供，可在自己的電腦運行。

> **本倉庫是 [galaxy-hzy/meridian-atlas](https://github.com/galaxy-hzy/meridian-atlas) 的香港繁體教學版**：介面全面轉為香港繁體中文，新增「認識穴位」與「都市人保健專區」兩個教學頁面，並改用 Cloudflare Workers 部署。詳見[本版改動](#本版改動相對上游)。

## 快速開始

需要 **Node.js 22 或以上版本**、npm，以及支援 WebGL 的現代瀏覽器。Python 僅用於可選的數據處理與研究腳本，日常運行不需要。

```bash
git clone https://github.com/forumdata-collab/meridian-atlas.git
cd meridian-atlas
npm install
npm run dev -- --host 127.0.0.1 --port 4318
```

開啟 **http://localhost:4318/**。

| 頁面 | 路徑 |
| --- | --- |
| 三維圖譜 | `/` |
| 十二時辰 | `/clock` |
| 配穴研習 | `/combinations` |
| 認識穴位 | `/learn` |
| 都市保健 | `/care` |
| 來源與校訂說明 | `/sources` |

建置並在本機預覽生產版本：

```bash
npm run build
npm start          # wrangler dev，預設 http://localhost:8787
```

執行時不需要配置 AI API 密鑰或 Cloudflare 帳號，首次安裝依賴需要聯網。外部參考連結和系統語音服務可能需要網絡。

手機使用：在手機瀏覽器開啟自己部署的 HTTPS 位址，可從瀏覽器選單選擇「加到主畫面」（支援情況取決於瀏覽器）。這仍是網頁應用，不是已上架應用商店的原生 App。

## 先試這條學習路線

1. 打開 **手太陰肺經**，在圖譜上旋轉、放大人體，觀察中府到少商的體表穴序。
2. 閱讀圖譜上方的歌訣，點擊 **歌訣注音**；開啟 **逐穴帶讀**，跟著高亮記憶穴序。
3. 在 **五輸 · 原 · 絡** 中點選太淵，查看它同時屬於「輸、原」的分類與定位出處。
4. 打開 **體內經過與分支**，對照《靈樞》的起點、屬絡及分支說明。
5. 切到 **十二時辰**，選擇寅時或播放全天，觀察傳統時辰與十二經的對應。
6. 進入 **配穴研習**，把一組文獻中的穴位帶回三維圖譜對照。
7. 逛一逛 **認識穴位** 與 **都市保健**，用 `/?points=LR3,LI4,PC6` 一次把多個穴位帶回人體對照。

## 功能詳解

### 1. 可以操作的三維經絡圖譜

- **旋轉、縮放、復位**：拖動人體、滾輪縮放，也可使用正面、背面、側面和縮放按鈕。
- **點經絡即高亮**：從經線或目錄選擇，集中觀察當前經絡；其他經絡、穴名和定位參考可分別開關。
- **兩層穴位資訊**：未選所屬經絡時顯示簡介；進入該經絡學習後，查看定位要點、傳統主治摘要、分類和原文連結。
- **重疊點選有候選項**：遇到重疊經線或穴點，可在選單中選定目標，支援鍵盤選擇和 Esc 取消。
- **標籤自動避讓**：按角度與空間隱藏部分標籤，減少畫面擁擠；目錄仍可查找並選擇穴位。
- **跨經穴組對照**：配穴連結可以一次帶入多個穴位，支援 `/?points=LU7,LI4` 這樣的可分享位址。

### 2. 認識穴位（初學指南）— `/learn`

<img src="docs/images/learn-guide.png" width="720" alt="認識穴位：什麼是穴位、取穴法、按揉手法與禁忌">

- **什麼是穴位**：腧穴的定義、經絡系統與氣血輸注的概念。
- **穴位的作用**：反映病候、輸注氣血、防治疾病。
- **如何取穴**：按揉四大原則（力度、頻率、時機、工具）與注意事項。
- **取穴方法**：同身寸（拇指同身寸 1 寸、四指橫量 3 寸）與體表標誌定位。
- **禁忌提示**：孕婦慎用穴、皮膚破損、急性不適等需先諮詢專業意見。

### 4. 十二正經、奇經八脈與十五絡脈

| 內容 | 已實現的學習方式 |
| --- | --- |
| 十二正經 | 手足三陰三陽，經穴目錄、表裡關係、前後經切換、體表線路、體內區域及分支示意 |
| 奇經八脈 | 任、督、衝、帶、陰蹺、陽蹺、陰維、陽維；文獻關聯穴、分段路線與八脈交會穴 |
| 十五絡脈 | 十二經之絡、任脈絡、督脈絡、脾之大絡；絡穴、原文、記憶提要及區域聯繫示意 |
| 經外奇穴 | 51 個國標條目與 6 個補充條目，可分別篩選，保留別名和穴組關係 |

任督脈與十二正經合為十四經，本項目按 **GB/T 12346-2021 收錄 362 個經穴條目**；另有 **51 個國標奇穴和 6 個補充條目**，共 **419 條記錄**。穴組與雙側顯示不重複計數。WHO 361 穴體系、印堂新舊歸屬等差異另作說明。

其餘六條奇經複用文獻關聯穴，不製造獨立標準穴位編號。十五絡也複用已有絡穴，不另造時辰配屬。

### 5. 穴位名稱、分類與來源一起學

- 全局搜尋中文穴名、經絡名、編號和別名；例如用「消渴」查找相關補充資料，用「胰俞」檢索胃脘下俞。
- 五輸穴 **井、滎、輸、經、合**，加上 **原、絡** 分類篩選；同穴多重分類合併保留。
- 顯示現代標準的定位要點、條款號與 PDF 頁碼，可跳轉核對原文。
- 傳統主治以文獻摘要呈現，並區分掃描核對、轉錄與二次資料等出處。
- 在詳情中保留模型定位依據及待核實項，讓「有來源」和「坐標已校準」各自清楚。

### 6. 歌訣、注音與輔助朗讀

- 《針灸大成》十四經歌訣顯示在三維圖譜上方，選經即切換。
- 古歌穴數、穴序與現代標準不同的地方單獨解釋，不靜默改寫古文。
- **逐穴帶讀**按現代穴序做視覺高亮，幫助把文字記憶與空間位置聯繫起來。
- **查讀音**支援輸入生字、詞語、穴名、歌訣，也可查詢頁面選中文字。
- 413 個標準穴名帶原拼音和來源索引；其餘文本用隨應用載入的拼音字庫處理，單字可展示多音項。
- 可調用瀏覽器或系統中文語音輔助朗讀；實際聲音與多音字讀法取決於運行環境。

### 7. 傳統時辰與動態循行

- 單經動態循行，觀察當前線路的方向和順序。
- 全天滑動時間軸、十二時辰快捷選擇和播放控制。
- 肺經寅時 03:00–05:00、膽經子時 23:00–01:00 等對應關係，包含跨午夜處理。
- 十二經體內經過及分支可與體表路線對照；虛線、區域投影等用於區分不同層次的示意。

這裡展示的是傳統時辰配屬和經脈理論，**不是現代血管、血流速度或生理能量測量模型**。

### 8. 配穴研習與古籍對照

- 獨立配穴頁面包含公開消渴文獻方案與證型加穴記錄、古籍用穴集合。
- 十二經主客原絡關係、四組八脈交會穴配對。
- 一鍵把穴組帶回人體，對比不同經絡上的位置。
- 《靈樞·經脈》循行原文、《針灸大成》歌訣及相關經典書目連結。
- 來源頁區分現代標準、古籍與現代健康資訊。列入書目不表示已完成對應古籍的全文校勘。

### 9. 適合自己運行，也適合繼續開發

- React、TypeScript、Three.js，主要交互在瀏覽器中運行。
- 中文響應式佈局；目錄、按鈕和候選選單提供畫布之外的操作入口。
- 無帳戶系統、無外部 AI 推理服務依賴；讀音查詢使用本地載入的數據。
- 可選 WebMCP 接口可以選擇經絡、查看穴位和設置學習時辰；瀏覽器不支援時仍可正常使用圖譜。
- 結構化數據、模型綁定、來源索引與處理腳本一起開放，便於審校和二次開發。

## 開發與驗證

```bash
npm run typecheck
npm test
npm run lint
npm run build
```

首個公開版本包含 **156 項自動測試**，覆蓋穴位目錄與編號、時辰邊界、分類、詳情顯示條件、配穴引用、網格綁定及經絡依賴等。另有實際瀏覽器點選、旋轉、時辰播放和佈局檢查記錄。自動測試不代表醫學或逐穴解剖驗證。

## 建置與部署（Cloudflare Workers）

```bash
npm run build
export CLOUDFLARE_API_TOKEN=<你的 API Token>
export CLOUDFLARE_ACCOUNT_ID=<你的 Account ID>
wrangler deploy --config dist/server/wrangler.json --domain acupoint.we1co.me
```

> **提示**：首次綁定自訂網域時，若該主機名已有外部管理的 DNS 記錄，`wrangler` 會回報 `code 100117`。先刪除該 CNAME，再由 `--domain` 自動建立即可（Worker 自訂網域會自行管理 DNS）。

## 資料來源與方法

- 穴名、編碼與定位：**GB/T 12346-2021《經穴名稱與定位》**（引用條款號與 PDF 頁碼）
- 傳統主治：**《針灸大成》**等古籍掃描條文節選，逐條標註出處
- 循行原文：**《靈樞·經脈》**及相關經典
- 人體模型：MakeHuman 基礎網格（CC0-1.0），穴位以表面吸附方式標記
- 逐穴解剖校準尚未完成；三維位置只作學習示意

「寸」為比例量度，不能換算為固定屏幕長度。

## 當前邊界與維護方向

這是可用的學習圖譜，**全身逐穴解剖校準尚未完成，不能用於臨床取穴或針刺操作**。通用人體並不代表每個人的骨骼、肌肉與體表標誌；傳統主治和配穴文獻不等同於現代臨床療效結論。

歡迎圍繞下列內容貢獻：

- 可復現的交互、佈局或運行問題；
- 有版本、頁碼和原文依據的穴名、讀音、歌訣與來源校訂；
- 與當前底模對應、可重複驗證的解剖定位改進；
- 鍵盤訪問、觸屏體驗、英文說明與學習流程改進。

未完成的校準項保留為明確待辦，不用測試數量或資料覆蓋率冒充定位準確率。
